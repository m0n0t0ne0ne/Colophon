Makes the chapter analyzer much faster.

- If a book already has chapter markers, the analyzer now listens only at those markers instead of scanning the whole book. Turn on **Scan the whole book** if chapters are missing.
- Whole-book scans now use several processor cores and spend less time waiting on the audio decoder.
- Progress now includes an estimate of the time left in each step.

**Download `colophon.apk`** on your phone and open it to update. Your library and positions are kept. Installing the update stops an analysis in progress, so start it again afterward.
